# 012 — SEO metadata and crawl logic

**Status:** todo  
**Depends on:** 005 for per-project metadata; site-wide pieces can ship earlier  
**Blocks:** none

## Goal

The public site is understandable to search engines and social previews: Slovak language, unique titles, Open Graph, sitemap, robots, and structured data. Admin stays out of the index.

## Site-wide (`src/app/layout.tsx` + Next metadata API)

- `html lang="sk"` (already).
- Default title: `Mirka Moravcová — Interiérový dizajn`
- `title.template`: `%s | Mirka Moravcová` for inner pages
- Description: current line or equivalent (*Tvorba priestorov s dôrazom na detail, funkčnosť a estetiku.*)
- `metadataBase` from `NEXT_PUBLIC_SERVER_URL` / `BETTER_AUTH_URL` (production canonical origin, not localhost)
- `openGraph`: type website, locale `sk_SK`, site name, title, description, image (`/images/hero.jpg` or a dedicated `og.jpg`)
- `twitter`: `summary_large_image`
- `robots`: index/follow on public pages
- Canonical on `/`

## Per page

- `/` — default metadata (do not suffix the homepage title twice)
- `/projekty/[slug]` — `generateMetadata`: title = project title, description = card description, OG image = cover, canonical `/projekty/[slug]`
- `/admin/**` — `robots: { index: false, follow: false }` in the admin layout

## Crawl files

- `src/app/sitemap.ts` — `/` + each **published** project URL; omit `/admin`
- `src/app/robots.ts` — allow `/`, disallow `/admin`, sitemap URL from `metadataBase`

## JSON-LD

One `<script type="application/ld+json">` on the homepage (or layout):

- `Person`: name Mirka Moravcová, jobTitle interior / spatial design, `address` Brno, `email`, `sameAs` Instagram from 011
- `WebSite`: name, url, `inLanguage: sk`
- Optional `creator` Organization: Nexelon s.r.o., url `https://nexelon.sk/` (visible credit is 013)

Project pages: `CreativeWork` or `ImageGallery` with name, description, image.

## On-page

- One `h1` on `/` (already), `h1` on project pages
- Meaningful `alt` on images (seed + admin later)
- Contact is a `mailto:` not a dummy form (010)

## Acceptance criteria

- [ ] View-source / share preview: title, description, og:image on home and a project slug.
- [ ] `/sitemap.xml` lists home + published projects only.
- [ ] `/robots.txt` disallows `/admin` and points at the sitemap.
- [ ] `/admin` responses include noindex.
- [ ] JSON-LD parses (no trailing-comma / invalid JSON).
