# 007 — Admin: create / edit project form

**Status:** done  
**Depends on:** 001, 006  
**Blocks:** 009

## Goal

A full-page form for one project. Homepage cards are a summary; this form is the source of the **whole** project page (text + cover + gallery).

## Routes

- `/admin/projekty/new`
- `/admin/projekty/[id]`

## Fields

| Field | UI |
| --- | --- |
| Title | text; slug autogenerated (editable) |
| Card description | textarea, short |
| Body | larger textarea, plain text, shown on `/projekty/[slug]` |
| Category | select: Rezidenčné / Komerčné / Koncepty |
| Tags | comma list or small chip input |
| Cover | UploadThing `projectCover` (one image, replaceable) |
| Gallery | UploadThing `projectGallery` (1–20), reorder by sort index, remove item |
| Published | checkbox |
| Sort order | number |

Save with tRPC `adminCreate` / `adminUpdate` (`adminProcedure`). Validate with Zod (slug unique, title required, cover required before publish).

On replace/remove image: `UTApi.delete` using stored `key` so UploadThing does not keep orphans.

Slovak labels and validation messages.

## Acceptance criteria

- [ ] Admin can create a project with several photos, publish, and see the card + detail page.
- [ ] Admin can edit copy, replace cover, add/remove gallery images, unpublish (disappears from public site).
- [ ] Non-admins cannot hit these mutations.
- [ ] Duplicate slug is rejected cleanly.

## Out of scope

- WYSIWYG / markdown preview, drag-and-drop gallery, hero/contact CMS.
